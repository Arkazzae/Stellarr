Stellarr

Text, voice and video chat for your friends, running on your own machine in one Docker container.

Your group's
own place

Text channels with threads, direct messages, voice channels with a soundboard, camera and screen sharing. Stellarr sends nothing to an outside service unless you switch on an integration yourself.

  • Voice quality Opus up to 256 kb/s, RNNoise or GTCRN noise filter
  • Screen sharing Up to 2160p at 60 fps, with system audio
  • Local translation Polish and English, translated in your browser
  • One container Web app, chat, voice server and database, one folder

Start your server

You need Docker with the Compose plugin. These commands download two files and start the container.

$ mkdir stellarr && cd stellarr $ curl -fsSLO https://raw.githubusercontent.com/Arkazzae/Stellarr/main/docker-compose.yml $ curl -fsSL https://raw.githubusercontent.com/Arkazzae/Stellarr/main/.env.example -o .env $ docker compose up -d

  1. Open https://localhost:8443Accept the warning about the container's self-signed certificate.

  2. Create the owner accountEnter the code from docker compose logs stellarr | grep "Setup code". Cockpit, the operator panel, is at /cockpit.

  3. Invite friends over the internetSet PUBLIC_IP and STELLARR_DOMAIN in .env, forward these ports and add a trusted HTTPS certificate.

  • 8443TCPWeb app and Cockpit
  • 49000UDPVoice and video
  • 3478UDPSTUN and TURN
  • 49160–49200UDPTURN relay
